# Nexi — Vault Obsidian + Claude Code

Vault de trabalho para um desenvolvedor de **integração de sistemas**: projetos, reuniões,
decisões técnicas, pessoas/áreas, runbooks e entregas, com o Claude Code rodando na raiz
e lendo o `CLAUDE.md` + as notas como memória.

> ⚠️ Repositório público: **todas as notas aqui são fictícias/genéricas**. O Vault real usa a mesma
> estrutura, com dado verdadeiro em `99-Privado/` (ignorada pelo git).

## Como usar
1. Abra a pasta como Vault no Obsidian.
2. No terminal, dentro da pasta: `claude`
3. Peça, por exemplo: `/resumo-semanal` ou "prepare o status da semana para o gestor".

Estrutura e regras do Claude: ver [CLAUDE.md](CLAUDE.md).
